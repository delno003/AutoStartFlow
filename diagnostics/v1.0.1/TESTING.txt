AutoStartFlow v1.0.1 - DIAGNOSTIC BUILD

This is a separate test build. The v1.0.0 release has not been changed.

Extract the whole folder. Run "Test startup.cmd" on the affected Windows PC.
Four diagnostic windows should open one at a time; close each to continue.
Do not install or update during this initial diagnostic test.

Collect these logs:
%LOCALAPPDATA%\AutoStartFlow\startup.log
%LOCALAPPDATA%\AutoStartFlow\startup-native-*.log

A successful test writes "DIAGNOSTIC WEBVIEW LOADED" for each runtime.
The four exit codes printed by the script should all be 0.
If a test fails, keep the logs even if later tests succeed.

The probe does not load/save startup profiles, register startup entries or
modify exe.xml. Normal Install/Update/Uninstall actions still behave normally;
use a test account/VM before exercising those actions.

The build includes an application-local .NET configuration for the downloaded
managed DLLs, early startup logging and launcher exit-code propagation.
No global Windows security settings or downloaded-file markers are changed.

This has not yet been certified on the affected work PC or clean Windows VMs.
README.md and installation.txt are the existing production usage documents.
